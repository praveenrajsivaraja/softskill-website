# KIKI, in short

KIKI is the purple chat button at the bottom right of the site. It answers questions about courses, learning, and, for administrators, the admin screens.

It is hidden on the login pages.

## How to use it

1. Click **KIKI**.
2. Type a question in everyday words. You do not need a special phrase.
3. Press **Enter** or **Send**. **Shift + Enter** starts a new line.
4. Read the answer. Steps are shown as points with an arrow. Purple pills open the matching page.
5. Use a related question under the answer to keep going.

The trash icon clears the chat. The X closes it. Closing does not delete anything on the site.

## How an answer is chosen

KIKI looks at the important words in the question, such as “courses”, “sales”, or “enroll”.

- A clear question gets a direct answer.
- Two possible meanings get a short question back, so you can say which one you meant.
- A course name, such as “spoken english”, searches the course list.
- A question it cannot place gets “I'm not able to understand that question.” plus related questions you can try.

Answers use the records already stored in KIKI Learning Hub for the person who is signed in.

## What a learner can ask

- Which courses are open, and how to enroll
- What is in the cart and checkout
- Where assessments are after enrollment
- “My” courses, progress, and scores, after sign-in

A learner sees their own learning. Platform totals, other people’s accounts, and sales stay with administrators.

## What an administrator can ask

The header says **Administrator** when an admin is signed in.

- How many courses, users, or enrollments there are
- Which course has the highest enrollment
- Average assessment score and inactive users
- Paid sales totals
- A platform overview
- Where to add a course, an assessment, materials, coupons, or a career test
- Where to review student scores and enrollments

The reply points to the admin screen that does the work. KIKI explains the steps. Creating accounts and changing passwords stays on the Users screen.

## Excel from the chat

When an answer includes numbers or a table, **Download report** saves that answer as an Excel file.

An administrator can also ask for a full report, for example:

- “Download the users report”
- “Download the sales report as Excel”
- “Export student progress”
- The same kind of request works for courses, enrollments, assessments, coupons, career tests, and the dashboard
- “Download all reports” puts those sheets in one file

The file starts downloading, and **Download report** on the answer downloads it again.

Each admin screen with a list also has its own **Download report** button. That file matches the rows on that screen, including the current search.

## Uploading a file

Administrators have a paperclip in the chat. It accepts CSV, TXT, PDF, and DOCX.

KIKI turns the file into rows for courses, assessments, or career-test page sections. The rows appear in the chat for review. Nothing is saved until you confirm. You can edit a cell or remove a row first.

Save an Excel file as CSV before uploading it.

## A few useful questions

Learners:

- “Show me the courses I can join.”
- “Which courses am I enrolled in?”
- “How do I enroll in a course?”
- “How do I check my assessment scores?”

Administrators:

- “How many courses are available?”
- “What is the total sales?”
- “Which users are inactive?”
- “How do I add an assessment?”
- “Download the sales report as Excel”
